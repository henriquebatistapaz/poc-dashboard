# Dashboard Mini

Private discovery project for a future integration between three existing private Java projects:

- `rss-collector-mini` — validates and parses RSS 2.0 and Atom 1.0 feeds.
- `collector-runner-mini` — normalizes, deduplicates, and persists social posts.
- `collector-mini` — collects Google News, Google Alerts, WordPress feeds, and Reddit through approved OAuth access.

## Current status

This repository contains a draft specification and no integration code. Its proposed runtime, API, persistence, and library integration are discussion points, not approved architecture. Data ownership, boundaries, and the integration contract need agreement before implementation.

All repositories remain private. AI-Ready files and generated `/docs/` are kept out of Git.
